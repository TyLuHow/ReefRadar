<objective>
Make the deterministic Lambda packager binary-safe before any binary member (contract `embeddings.f32`, the OOD reference `.f32`, the successor model `.npz`) is added to a package spec.

Purpose: `scripts/lambda_packaging.py:86-92` (`_default_reader`) and `scripts/deploy-lambdas.py:101` (`git_show_reader`) pass every member through `normalize_text_bytes` (CR LF to LF). A binary file that happens to contain the byte pair 0x0D 0x0A would be silently corrupted in the deployed zip (RESEARCH Pitfall 1, CONTEXT amendment "Packaging bug (must fix first)"). Later plans bundle the reference embeddings, the OOD artifact and the successor weights into the classifier zip (CONTEXT "Reference similarity is pinned"), so this must land first. D-03 (drift check) and D-04 (one scripted deploy path) depend on every reader agreeing.

Output: a suffix-based binary allowlist shared by every reader, with tests that would have caught the corruption.
</objective>
