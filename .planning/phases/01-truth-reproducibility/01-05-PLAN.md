## STRIDE Threat Register

|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-05-01 | Tampering | deploy-lambdas.py / drift-check.py arguments | high | mitigate | --function validated against the four spec filenames; subprocess only with argument lists; no shell=True (asserted by acceptance criteria) |
| T-01-05-02 | Elevation of Privilege | accidental production deploy | high | mitigate | Non-dry-run requires --confirm; dirty-tree refusal; actual deploys only run in plan 01-14 behind a blocking-human checkpoint |
| T-01-05-03 | Information Disclosure | drift reports | medium | mitigate | Reports include environment variable names only, never values; presigned Code.Location URLs are never printed |
| T-01-05-04 | Tampering | archive parsing (zip, tar layers) | medium | mitigate | Archives are read in memory and only hashed; nothing is extracted to disk, so path traversal in member names cannot write files |
