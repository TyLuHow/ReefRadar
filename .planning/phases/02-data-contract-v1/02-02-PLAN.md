<objective>
Create the AWS side of the contract: first the owner's $25/month budget alarm (it must exist before any contract publish), then the private contract bucket served through CloudFront with origin access control, managed caching and wildcard CORS for public credential-free GETs. Everything goes through one idempotent script with --dry-run and --confirm, and the resulting resource identifiers are recorded in infrastructure/resources.json.

Purpose: CONTRACT-01 needs CDN-served, app-deploy-independent storage (CONTEXT "Hosting and publishing"), and the owner's budget decision (CONTEXT "Owner decisions after research") requires the alarm before the first publish. The CloudFront domain recorded here becomes the web app's default contract base URL in plan 02-07. CORS (CONTEXT: "CORS for the dashboard origins and localhost") is satisfied with the AWS managed SimpleCORS policy (Access-Control-Allow-Origin "*", no credentials), which covers the dashboard origins, localhost and the unpredictable *.vercel.app preview hosts; this is the research recommendation within the CONTEXT discretion over CloudFront settings, appropriate because the data is public, open-licensed and fetched without credentials.
Output: scripts/setup_contract_infra.py (+ tests), live budget/bucket/OAC/distribution/policy, resources.json and DEPLOY-LOG.md entries.
</objective>
