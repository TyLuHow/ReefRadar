## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-08-01 | Tampering | path injection via ?cv | medium | mitigate | Strict integer regex (1-6 digits); only the parsed integer reaches URL construction; tested with path-like and malformed values |
| T-02-08-02 | Spoofing | silent fallback misrepresents the version shown | high | mitigate | Missing or invalid pin renders a visible alert and makes no latest request; pinned flag exposed on the document |
| T-02-08-03 | Tampering | poisoned pointer | medium | mitigate | Pointer's manifest_sha256 verified against the manifest bytes (02-07 client) before use |
| T-02-08-04 | Denial of Service | 60 s pointer polling cost | low | accept | One ~150-byte cached request per minute per open tab, served from the CDN; bounded by the 25 USD budget alarm |
