## Branch and CI rules (all tasks)

- Work only on `redesign/v2-discovery`. Never merge to main, never run `vercel deploy --prod` or `vercel promote`.
- Run every git, gh and npm command on its own (no `&&` chains). Push only with `git push origin redesign/v2-discovery`.
- The snapshot dispatch is exactly `gh workflow run CI --ref redesign/v2-discovery -f update_snapshots=true` (allow-listed). Never push, and never start another dispatch, while it runs: CI concurrency cancels in-progress runs on the same ref.
- Windows renders are never committed; only PNGs downloaded from the dispatch artifact are.
- Downloads go to the session scratchpad; only the changed baseline PNGs and the generated review page enter the repository.
- Never print tokens, presigned URLs or personal email addresses.
