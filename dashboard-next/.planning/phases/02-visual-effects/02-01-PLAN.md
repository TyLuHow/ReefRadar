Create `src/hooks/useBackgroundCanvas.ts` exporting a single hook `useBackgroundCanvas(canvasRef: RefObject<HTMLCanvasElement | null>): void`.

**PoolParticle interface** (all fields mutable, reset in-place):
```
active: boolean
x, y, vx, vy: number
size: number
alpha, maxAlpha: number
life, maxLife: number
hue, saturation, lightness: number
```

**createPool(size: number)**: Returns `PoolParticle[]` of 150 pre-allocated objects with `active: false`. Called ONCE at hook init via `useRef`.

**lerp(a, b, t)**: Simple linear interpolation helper (`a + (b - a) * t`).

**resetParticle(p, vitality, width, height)**: Resets an inactive particle in-place:
- `p.active = true`
- `p.x = Math.random() * width` (random horizontal position)
- `p.y = height * (0.7 + Math.random() * 0.3)` (bottom third)
- `p.vy = -(lerp(0.3, 1.5, vitality))` (negative = upward, speed per user decision)
- `p.vx = (Math.random() - 0.5) * 0.3` (slight initial horizontal drift)
- `p.size = lerp(2, 6, vitality * Math.random())` (2-6px per user decision)
- `p.maxAlpha = lerp(0.2, 0.8, vitality)` (opacity per user decision)
- `p.alpha = 0` (starts invisible, life curve handles fade-in)
- `p.life = 0`
- `p.maxLife = 120 + Math.random() * 180` (2-5 sec at 60fps)
- Color: if `vitality < 0.3` -> `hue=30, sat=40, light=45` (muted ochre-brown). Else: 60% chance `hue=175` (teal), 40% chance `hue=320` (magenta), `sat=lerp(40, 80, vitality)`, `light=lerp(45, 55, vitality)`.

**spawnParticles(pool, vitality, width, height, time)**:
- `targetCount = Math.round(lerp(5, 150, vitality))`
- Count active particles via loop (no `.filter()` -- avoid allocation)
- `deficit = targetCount - activeCount`
- `spawnsThisFrame = Math.min(deficit, 3)` (cap 3 per frame for smooth ramp)
- For each spawn, find first `!p.active` slot and call `resetParticle`

**updateParticles(pool, vitality, time, width, height)**:
- For each active particle:
  - `p.life++`
  - `p.y += p.vy` (drift upward)
  - `p.x += p.vx + Math.sin(time * 0.02 + p.y * 0.01) * 0.3` (horizontal oscillation per research recommendation)
  - Life curve (from useSpectrogramAnimation pattern): `lifeProgress = p.life / p.maxLife`. If `< 0.2`: `alpha = (lifeProgress / 0.2) * maxAlpha`. If `> 0.7`: `alpha = ((1 - lifeProgress) / 0.3) * maxAlpha`. Else: `alpha = maxAlpha`.
  - If `p.life >= p.maxLife || p.y < -10` -> `p.active = false` (deactivate, do NOT splice)
- Then call `spawnParticles` to replenish

**drawParticles(ctx, pool)**:
- `ctx.globalCompositeOperation = 'source-over'`
- Pre-compute color strings ONCE per vitality band (avoid per-particle string allocation -- Pitfall 5):
  - Cache 3 color strings: degraded-brown, teal, magenta. Recompute only when vitality band changes.
  - For each active particle: create radial gradient from `hsla(hue, sat%, light%, alpha)` at center to transparent at `size * 2`. Use `ctx.beginPath(); ctx.arc(); ctx.fillStyle = gradient; ctx.fill()`.
  - To mitigate Pitfall 5: build the hsla string per-particle but use integer alpha bucketing (round alpha to nearest 0.05) to enable some reuse.

**useEffect body** (the rAF loop):
- Get canvas and ctx (once). Guard: `if (!canvas || !ctx) return`.
- Create `runningRef` guard (StrictMode pattern from useVitality).
- DPR-aware resize via ResizeObserver (exact pattern from useSpectrogramAnimation): `canvas.width = w * dpr; canvas.height = h * dpr; ctx.setTransform(dpr, 0, 0, dpr, 0, 0)`.
- `animate` function:
  1. `const vitality = useVitalityStore.getState().target;`
  2. `timeRef.current += 1;`
  3. `ctx.clearRect(0, 0, width, height);`
  4. Call `updateParticles(pool, vitality, time, width, height)` (includes spawn)
  5. Call `drawParticles(ctx, pool)`
  6. `rafId = requestAnimationFrame(animate);`
- Cleanup: `cancelAnimationFrame(rafId); ro.disconnect(); runningRef.current = false;`
