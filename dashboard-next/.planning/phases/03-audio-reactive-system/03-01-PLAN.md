**Create `src/hooks/useAudioVisualBridge.ts`:**

This hook reads FFT data from an AnalyserNode, computes 4-band RMS energy, and writes to the vitality store at ~30fps.

Parameters: `analyserRef: RefObject<AnalyserNode | null>, audioCtxRef: RefObject<AudioContext | null>, isPlaying: boolean`

Key implementation details:

1. **Pre-allocate** a `Uint8Array` of size `analyser.frequencyBinCount` once (via useRef). Reuse it every frame.

2. **Bin calculation** — CRITICAL: Use `audioContext.sampleRate` (NOT file sample rate). Compute at init:
   ```
   hzPerBin = audioContext.sampleRate / analyser.fftSize
   binForHz(hz) = Math.min(Math.round(hz / hzPerBin), analyser.frequencyBinCount - 1)
   ```

3. **Band definitions** (constant object, not allocated per frame):
   ```
   ambient: { lo: 0,    hi: 200   }
   fish:    { lo: 200,  hi: 2000  }
   grazing: { lo: 1000, hi: 4000  }
   shrimp:  { lo: 2000, hi: 20000 }
   ```
   Note: shrimp hi should be clamped to `sampleRate / 2` to handle devices with <40kHz sample rates.

4. **RMS function** (pure, no allocation):
   ```
   function bandRMS(data: Uint8Array, start: number, end: number): number {
     if (end <= start) return 0;
     let sumSq = 0;
     for (let i = start; i < end; i++) {
       const v = data[i] / 255;
       sumSq += v * v;
     }
     return Math.sqrt(sumSq / (end - start));
   }
   ```

5. **rAF loop** — use a frame counter to throttle to ~30fps (process every other frame). Only read FFT when `isPlaying` is true. When not playing, skip FFT read (band energy stays at last value until unmount cleanup).

6. **Write to store** each analysis frame:
   ```
   useVitalityStore.getState().setBandEnergy(energy)
   ```
   No React subscription needed — just direct store mutation.

7. **Cleanup on unmount**: Cancel rAF, reset band energy to all zeros via `setBandEnergy({ ambient: 0, fish: 0, grazing: 0, shrimp: 0 })`. This prevents stale bursts after navigating away from the experience page.

8. **Export**: `export function useAudioVisualBridge(analyserRef, audioCtxRef, isPlaying): void`
